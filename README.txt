Food, LLC — Coursera Module 3 assignment

Files:
- index.html
- css/styles.css
- images/grilled-chicken.jpg

How to run:
1. Extract the ZIP file.
2. Open the food_llc_assignment folder in VS Code.
3. Open index.html with Live Server, or open it directly in a browser.

Notes:
- No JavaScript is used.
- The mobile menu uses a CSS checkbox toggle.
- Bootstrap 3 CSS is included from its CDN for the container/grid/text utility classes.
- The navbar menu is hidden on desktop/tablet and shown on mobile.
- The assignment's required single tall section is retained.
- Internet is needed to load Bootstrap CSS from the CDN.
